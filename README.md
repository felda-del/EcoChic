# EcoChic

EcoChic is a front-end web project focused on sustainable fashion and lifestyle education. It was designed to turn a broad social issue into a practical, user-friendly digital experience by combining educational content with interactive tools that encourage more thoughtful everyday choices.

This project demonstrates the ability to plan, design, and build a polished multi-page website with responsive layouts, consistent branding, and JavaScript-driven interactivity.

## Project Overview

EcoChic was created to make sustainable fashion feel more approachable, actionable, and relevant to everyday users. Rather than presenting information alone, the site encourages engagement through interactive features such as a product explorer, a style quiz, a progress tracker, and a sustainability calculator.

The project reflects a balance of visual design, front-end structure, usability, and user-focused thinking.

## Key Features

- Responsive multi-page website built with HTML, CSS, and JavaScript
- Consistent navigation and footer across all pages
- Product Explorer with search, category filtering, sorting, and saved favorites
- Style Quiz with personalized recommendation logic
- Progress Tracker for monitoring sustainable habits
- Sustainability Calculator with dynamic score generation
- Contact form with client-side validation and live feedback
- Rotating eco tips on the homepage
- Newsletter popup interaction
- Scroll reveal animations for a more engaging browsing experience
- Curated resources page with external sustainability content

## Pages Included

- `index.html` – Landing page and project introduction

## How to Run

1. Download or clone the repository.
2. Make sure the project files are in the main folder.
3. Open `index.html` in a web browser.

No installation or build tools are required.
